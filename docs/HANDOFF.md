## Разрешённая цель

Пользователь поручил создать отдельную папку/репозиторий, выложить через GitHub на сервер и проверить быстродействие. Уточнил: сервер тот же, что у 1C-ИП v2, но изолированно от других проектов. Из его актуального deployment найдена цель89.208.213.14. Планируемый новый root /srv/dltk-v3-test; существующий код /srv/ip_ya, его данные и настройки сайтов не изменять; разрешены новые конфигурации стенда в общих службах по последнему решению пользователя. Наличие старых полномочий 1C-ИП не является разрешением менять тот проект.

## Текущий доступ и решение пользователя

SSH user + sudo работает с закреплённым hostkey. Данные входа не сохраняются в проекте. SQL-копия передана в закрытый staging-каталог отдельно от Git. Проект на сервере ещё не установлен.

Последнее решение пользователя: использовать общие службы PHP 8.4 / MySQL 8.4 / Apache. Отдельная схема dltk_v3_test и учётка БД, PHP-пул, Apache-сайт :8443, каталог /srv/dltk-v3-test и WS-служба. Существующий MySQL доступен только через /var/run/mysqld/mysqld.sock; не включать TCP, не менять его конфигурацию и не перезапускать. Новые сайт/пул применяются graceful reload Apache/PHP. Требуется mbstring и proxy_fcgi. Старый provision_native.py НЕ запускать: готовится provision_shared.py. Существующий TLS-сертификат IP обслуживается штатным процессом, новый сайт использует тот же путь без копирования закрытого ключа.
