# ЛК ДЛТК V3 — отдельный серверный стенд

Самостоятельная серверная копия локальной витрины. Код доставляется из этого закрытого репозитория; рабочая БД и runtime-настройки передаются отдельно по SSH и в Git не входят.

Система: пять самостоятельных таблиц, шесть равноправных типов сотрудников, справочники, персональные настройки, общий и построчный журнал, WebSocket-обновления и присутствие редакторов. Четыре дополнительные таблицы пока демонстрационные. Google не подключается.

Проверенный адрес стенда: **https://89.208.213.14/dltk-v3/**. Входы и пароль — только в приватном файле доступа.

## Целевая изоляция

- Каталог `/srv/dltk-v3-test`; общие MySQL, PHP-FPM и Apache по решению пользователя.
- Собственный раздел `/dltk-v3/` существующего HTTPS443, PHP-пул и WS `127.0.0.1:33486`.
- Отдельная БД `dltk_v3_test` и DB-пользователь через существующий Unix socket; отдельный пользователь ОС.
- Существующие сайты, пулы и данные сохраняются. Добавление конфигурации стенда применяется плавной перезагрузкой PHP-FPM/Apache; MySQL не перезапускается.

На целевом Debian используются существующие службы PHP 8.4, MySQL 8.4 и Apache. Docker-конфигурация и прежний вариант полностью отдельных процессов сохранены как альтернативы; это не действующая схема выкладки.

GitHub Actions проверяет PHP/JS/Python и собирает архив точного коммита с SHA256. Успешный push в `main` автоматически выкладывает этот архив на стенд. Подробности: [автодеплой](docs/AUTODEPLOY.md). Первое развёртывание выполняется `deploy/provision_shared.py` с проверенным артефактом и отдельным SQL-снимком. Скрипт отказывается перезаписывать существующую установку или импортировать данные поверх непустой БД.

Доступы к демоаккаунтам хранятся в приватном файле сервера. Локальные пароли автоматически не публикуются.
