# ЛК ДЛТК V3 — отдельный серверный стенд

Самостоятельная серверная копия локальной витрины. Код доставляется из этого закрытого репозитория; рабочая БД и runtime-настройки передаются отдельно по SSH и в Git не входят.

Система: пять самостоятельных таблиц, шесть равноправных типов сотрудников, справочники, персональные настройки, общий и построчный журнал, WebSocket-обновления и присутствие редакторов. Четыре дополнительные таблицы пока демонстрационные. Google не подключается.

## Целевая изоляция

- Каталог `/srv/dltk-v3-test`; отдельные MySQL, PHP-FPM, WebSocket и Apache.
- HTTPS `:8443`, MySQL `127.0.0.1:33484`, WS `127.0.0.1:33486`, FPM `127.0.0.1:33487`.
- Отдельная БД `dltk_v3_test`, пользователь ОС и systemd-службы `dltk-v3-*`.
- Другие проекты сервера не изменяются и не перезапускаются.

На целевом Debian используются существующие бинарные файлы PHP 8.4, MySQL 8.4 и Apache. Дополнительный модуль PHP извлекается в каталог проекта. Docker-конфигурация сохранена как необязательный вариант и не означает, что Docker установлен на сервере.

GitHub Actions проверяет PHP/JS/Python и собирает архив точного коммита с SHA256. Сам push не изменяет сервер. Первое развёртывание выполняется `deploy/provision_native.py` с проверенным артефактом, отдельным SQL-снимком и TLS-файлами. Скрипт отказывается перезаписывать существующую установку или импортировать данные поверх непустой БД.

Доступы к демоаккаунтам хранятся в приватном файле сервера. Локальные пароли автоматически не публикуются.
