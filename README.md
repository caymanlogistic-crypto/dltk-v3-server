# ЛК-ДЛТК V3 · серверный репозиторий

PHP, MySQL и Python WebSocket. В кабинете работают «Вывоз», четыре демонстрационные таблицы, справочники, личные настройки и журнал. Шесть типов сотрудников имеют равный доступ.

[Задачи и решения](https://app.notion.com/p/41da64edce32819e82add67138cf52bd?pvs=204) · [Стенд](https://89.208.213.14/dltk-v3/) · [GitHub Actions](https://github.com/caymanlogistic-crypto/dltk-v3-server/actions/workflows/check.yml)

## Быстрый старт

1. Открой поручение и свою карточку в Notion. Уточни ветку, текущий цикл и нужную проверку в [порядке работы](docs/AGENT_WORKFLOW.md).
2. При правке сайта работай с этим репозиторием в отдельном worktree. Исходная Windows-папка «ЛК-ДЛТК V3» содержит локальный стенд, Витрину и архив проектных исследований. Сервер получает код из этого репозитория. Связь между копиями показана в [технической карте](docs/ARCHITECTURE.md).
3. Запусти [проверки из worktree](docs/LOCAL_QA.md). Для UI сначала открой [Витрину](app/local-admin/VITRINE.md) и проверь соответствующий пример.
4. Обнови документацию рядом с кодом и приложи проверку к карточке и PR. Слияние в `main` выполняется по команде «выкладывай». [Порядок выкладки](docs/AUTODEPLOY.md).
